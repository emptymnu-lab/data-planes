# Flight Lab — первый проект по анализу данных

Небольшой проект для знакомства с программированием и Data Analysis: исследуем реальные авиарейсы из Нью-Йорка за 2013 год. Можно фильтровать данные, сравнивать средние задержки и смотреть популярные направления.

## Запуск

Нужен Python 3.10 или новее. Устанавливать библиотеки, получать API-ключи и создавать аккаунты не нужно: CSV уже лежит в проекте, приложение работает без интернета.

```bash
cd /workspace/data-planes
python3 app.py
```

На своём компьютере перейди в папку проекта и выполни ту же команду; на Windows команда может называться `python`. Затем открой в браузере адрес, который напечатает сервер. Остановка — Ctrl+C. Если порт занят: `python3 app.py --port 8001`.

В облачной среде доступ к интерфейсу зависит от поддержки проброса портов в используемом клиенте. Запущенный процесс сам по себе не создаёт публичный сайт.

## Откуда данные и что они означают

Источник: открытый набор [nycflights13](https://cran.r-project.org/package=nycflights13), опубликованный в CSV в [Rdatasets](https://github.com/vincentarelbundock/Rdatasets/blob/master/csv/nycflights13/flights.csv). Описание исходных столбцов: [документация flights](https://vincentarelbundock.github.io/Rdatasets/doc/nycflights13/flights.html).

В проект включены первые 200 строк каждого месяца в порядке исходного CSV, всего 2 400 записей, и только используемые столбцы. Это намеренно маленькая, **нерепрезентативная выборка**: она охватывает все месяцы, но не все дни и часы. Результаты описывают только выбранные записи. Это исторические данные, а не табло текущих рейсов.

- `year`, `month`, `day` — дата вылета.
- `origin` — аэропорт вылета: JFK, LGA или EWR.
- `dest` — код аэропорта назначения.
- `carrier` — код авиакомпании, например AA. В разных фильтрах компании представлены неодинаково.
- `dep_delay`, `arr_delay` — задержка вылета и прилёта в минутах. Отрицательное число означает раньше расписания.
- `air_time` — время в воздухе, минуты; `distance` — расстояние в милях.
- `hour` — плановый час вылета.
- `NA` — отсутствующее значение; это не ноль и само по себе не доказательство отмены рейса.

Средняя задержка = сумма известных задержек / число известных задержек.
Доля задержанных = число известных задержек **строго больше 15 минут** / число известных задержек × 100%. Рейс с задержкой ровно 15 минут в эту долю не входит. Число рейсов включает записи с пропусками, а показатели задержек — только записи с измерениями. Если измерений нет, показывается «нет данных».

## Учебный маршрут

1. **Исследуй страницу.** Сравни JFK и LGA, затем выбери месяц. Запиши наблюдение и размер выборки. Не делай вывод о «лучшей авиакомпании» по одному среднему.
2. **Прочитай CSV.** Открой первые строки в редакторе. Найди код аэропорта, задержку и дату одного рейса.
3. **Запусти Python отдельно от сайта.** Из папки проекта:

   ```bash
   python3 -c "from analysis import load_flights, summarize; print(summarize(load_flights()))"
   ```

   Найди в `analysis.py` строки, которые считают среднее. Объясни каждую своими словами. `rows` — список записей, каждая запись — словарь: например, `row['dest']` возвращает аэропорт назначения.
4. **Сделай первое изменение.** Добавь в результат `summarize()` максимальную известную задержку. Для пустой выборки верни `None`. Сначала выведи результат командой выше; затем попробуй добавить показатель на страницу.
5. **Научись проверять выводы.** Добавь медиану через стандартный модуль `statistics` и сравни её со средним. Почему они различаются? Проверь на списке `[0, 0, 0, 120]`.
6. **Следующий шаг.** Добавь фильтр аэропорта назначения. Позже перенеси CSV в SQLite и сравни группировку в Python с запросом SQL `GROUP BY`.

Старайся менять одну вещь за раз: сформулируй вопрос → получи данные → посчитай → проверь → объясни результат простыми словами. Не нужно сразу разбираться во всех файлах.

## Проверки

```bash
python3 -m unittest discover -s tests -v
```

Тесты проверяют среднее, отрицательные задержки, границу 15 минут, пропуски и пустую выборку. Работающий сервер отдаёт JSON по `/api/flights`; пример фильтра: `/api/flights?origin=JFK&month=1`.

Проект использует только стандартную библиотеку Python, обычный JavaScript и CSS, без этапа сборки. Сервер предназначен для локального обучения, не для размещения в открытом интернете.
