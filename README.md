# Flight Atlas — исследуем аэропорты мира

Интерактивная карта аэропортов на Python и JavaScript. Россия, Китай, США, Европа и остальные страны мира: поиск по названию, городу и коду, фильтры типов, карточки объектов и сравнение стран.

Это **справочник аэропортов**, а не сервис отслеживания самолётов. Маршруты, билеты, расписания, пассажиропоток и текущие задержки не представлены. Наш первый этап — научиться собирать, проверять и исследовать географические данные; данные о рейсах требуют отдельного источника.

## Запуск

Нужен Python 3.10+. Внешние Python-библиотеки, API-ключи и сборка интерфейса не требуются.

```bash
cd /workspace/data-planes
python3 app.py
```

На своём компьютере перейди в скачанную папку проекта. На Windows команда может называться `python`. Открой в браузере напечатанный сервером адрес. Остановка — Ctrl+C. Другой порт: `python3 app.py --port 8001`.

Данные, географическая подложка и Leaflet включены в репозиторий. Работа карты не зависит от внешних картографических серверов. На большом приближении нет улиц и спутниковых снимков: это обзорная карта стран. В облачной среде возможность открыть интерфейс зависит от поддержки проброса портов клиентом.

### Render

Создай **Web Service**, подключи этот репозиторий и ветку `main`:

- Runtime: Python 3.
- Build Command: `pip install -r requirements.txt`.
- Start Command: `python3 app.py --host 0.0.0.0 --port $PORT`.
- Root Directory: оставь пустым, файлы находятся в корне репозитория.

После деплоя Render выдаст публичный адрес. Это учебный сервер на стандартной библиотеке Python, без авторизации; он подходит для демонстрации открытых данных. Для серьёзной нагрузки понадобится отдельная серверная инфраструктура.

## Что можно делать

- Быстро выбирать мир, Россию, Китай, США или Европу.
- Уточнять страну, тип объекта и наличие регулярного сообщения.
- Искать название, город, IATA, ICAO или внутренний идентификатор. Названия из источника преимущественно английские: например, `Moscow`, `Beijing`, `SVO`, `JFK`. Некоторые записи содержат поисковые варианты на других языках, но полная русская локализация отсутствует.
- Нажимать точки или строки списка, чтобы открыть карточку и перейти к записи источника.
- Сравнивать число объектов по странам при текущих фильтрах.

По умолчанию видны объекты с `scheduled_service=yes`, кроме закрытых. Это отметка источника, не проверка текущего расписания. «Кроме закрытых» исключает только тип `closed`: такая классификация не гарантирует фактическую работу объекта сегодня. «Все записи» включает закрытые аэропорты, вертодромы, гидроаэродромы и другие площадки.

Для отзывчивой карты показываются максимум **6 000 объектов**, сначала крупные, затем средние. Интерфейс сообщает об ограничении; статистика и рейтинг рассчитываются по **всем** найденным строкам. Уточни страну или поисковый запрос, чтобы найти объекты за пределами первых 6 000. Список раскрывается по 20 записей.

## Данные и ограничения

**Аэропорты:** [OurAirports](https://github.com/davidmegginson/ourairports-data), файлы `airports.csv` и `countries.csv`. Источник обновляет выгрузки ежедневно, но приложение использует сохранённый снимок. Дата его получения, SHA-256 исходных файлов и число строк находятся в `data/airports-meta.json`. Это дата получения файлов, а не дата индивидуальной проверки каждого аэропорта.

OurAirports публикует данные как public domain. [Описание лицензирования в зеркале datasets](https://github.com/datasets/airport-codes) также отмечает неопределённость условий отдельных исходных источников и списков кодов IATA/ICAO. Это общественный справочник: наличие записи не гарантирует полноту, актуальность или пригодность для навигации. Не используй проект для выполнения полётов.

**Границы:** [Natural Earth, 1:110m](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson), public domain. Карта обзорная, её границы могут отличаться от географических категорий аэропортов. Фильтр «Европа» использует значение `continent=EU` в OurAirports, а не членство в Евросоюзе. Россия также доступна отдельным фильтром по коду RU.

**Картографическая библиотека:** Leaflet 1.9.4, BSD-2-Clause; лицензия в `static/vendor/LEAFLET-LICENSE`.

Не делай вывод о пассажиропотоке по числу аэропортов: множество малых аэродромов и один крупный узел — разные явления. Не называй отметку `scheduled_service` доказательством существования рейса сегодня.

### Обновить аэропорты

Из корня проекта, с доступом к `raw.githubusercontent.com`:

```bash
python3 scripts/update_airports.py
python3 -m unittest discover -s tests -v
```

Скрипт скачивает два файла по HTTPS, проверяет столбцы, сохраняет используемые поля и метаданные. После обновления перезапусти сервер. Во время обычного запуска интернет для данных не нужен.

## Как устроен проект

```text
OurAirports CSV → Python: загрузка и проверка координат
               → фильтры и группировка
               → HTTP API с JSON
               → JavaScript + Leaflet: карта, карточки и статистика
```

| Файл | Что изучать |
| --- | --- |
| `airports.py` | CSV, типы данных, фильтры, словари, группировка через Counter |
| `app.py` | HTTP-сервер, параметры запроса, JSON |
| `static/app.js` | Запросы к API, события, карта, обновление интерфейса |
| `static/index.html` | Структура страницы и формы |
| `static/style.css` | Оформление, адаптация под телефон |
| `scripts/update_airports.py` | Получение, проверка и происхождение данных |
| `tests/test_airports.py` | Проверки фильтров, статистики и API |

HTML — язык разметки, CSS — язык оформления. Python и JavaScript — языки программирования. SQL добавим следующим этапом, когда научимся группировать таблицы в Python.

Предыдущий маленький пример задержек Нью-Йорка сохранён в `analysis.py`, `data/flights.csv` и `/api/flights`. Он не используется в мировой карте. Источник примера: [nycflights13 / Rdatasets](https://github.com/vincentarelbundock/Rdatasets/blob/master/csv/nycflights13/flights.csv), первые 200 строк каждого месяца 2013 года, всего 2 400 записей. Эта выборка нерепрезентативна.

## API и проверки

- `/api/meta` — происхождение снимка, страны и типы объектов.
- `/api/airports` — статистика и точки с регулярным сообщением по миру.
- `/api/airports?scope=RU&q=SVO` — поиск Шереметьево.
- `/api/airports?scope=EU&service=open&type=large_airport` — крупные аэропорты в европейской категории источника, кроме закрытых.
- Параметры: `scope` (`world`, `EU` или код страны), `country`, `type`, `service` (`scheduled`, `open`, `all`), `q`.

## Первые задания для тебя

1. Найди SVO и PEK. Объясни разницу между IATA, ICAO и внутренним идентификатором.
2. Выбери США. Сравни число объектов при регулярном сообщении и при всех типах. Объясни, почему показатели так различаются.
3. Прочитай `filter_airports()` в `airports.py`. Найди условие для Европы и условие для закрытых объектов.
4. Посчитай долю крупных аэропортов в выбранной стране: число крупных / число объектов × 100. Назови знаменатель и фильтры, без них показатель неоднозначен.
5. Следующее изменение в коде: добавить показатель числа средних аэропортов. Сначала расчёт и тест, затем API и карточка на странице.

Следующий этап развития — SQLite и сравнение стран через SQL. После этого можно исследовать открытые данные маршрутов: сначала проверить дату, лицензию и покрытие России, Китая, США и Европы, затем рисовать подтверждённые связи. Линии между произвольными аэропортами нельзя выдавать за реальные рейсы.
